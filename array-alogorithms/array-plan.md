# Array Coding Interview Questions

## Description
The following list of 50 array coding problems covers a range of difficulty levels, from easy to hard, to help candidates prepare for interviews. Each section includes a list of specific problems with brief descriptions.

## Easy Problems

1. **Second Largest Element** - Find the second largest number in an array.
2. **Third Largest Element** - Find the third largest number in an array.
3. **Reverse an Array** - Reverse the elements of an array.
4. **Reverse Array in Groups** - Reverse the elements of an array in groups of a specified size.
5. **Rotate Array** - Rotate the elements of an array to the right by a given number.
6. **Three Great Candidates** - Arrange an array in a pattern such that the first element is the largest, the second is the smallest of the remaining, and so on.
7. **Max Consecutive Ones** - Find the maximum number of consecutive 1s in an array.
8. **Move All Zeroes To End** - Move all zeroes in an array to the end while maintaining the order of non-zero elements.
9. **Wave Array** - Arrange the elements of an array in the following order: 1st smallest, 2nd largest, 3rd smallest, 4th largest, and so on.
10. **Plus One** - Increment a number represented as an array.
11. **Stock Buy and Sell – One Transaction** - Find the maximum profit from buying and selling stocks exactly once.
12. **Stock Buy and Sell – Multiple Transactions** - Find the maximum profit from buying and selling stocks any number of times.
13. **Remove Duplicates from Sorted Array** - Remove duplicate elements from a sorted array in place.
14. **Alternate Positive Negative** - Arrange the elements of an array such that positive and negative numbers alternate.
15. **Array Leaders** - Identify elements in an array that have all elements on their left side smaller and all elements on their right side greater.
16. **Missing and Repeating in Array** - Find a missing and a repeating number in an array containing elements from 1 to n.
17. **Missing Ranges of Numbers** - Find the missing ranges of numbers in a sorted array.
18. **Sum of all Subarrays** - Find the sum of all subarrays of an array.

## Medium Problems

1. **Next Permutation** - Rearrange the string to get the next smallest lexicographical sequence.
2. **Majority Element** - Find the element that appears more than n/2 times in an array.
3. **Majority Element II** - Find all elements in an array that appear more than n/3 times.
4. **Minimize the Heights II** - Reduce the difference between the maximum and minimum height of the bars in an array.
5. **Maximum Subarray Sum** - Find the contiguous subarray with the largest sum.
6. **Maximum Product Subarray** - Find the contiguous subarray with the largest product.
7. **Product of Array Except Self** - Find the product of all elements in the array except the element at the current index.
8. **Subarrays with Product Less Than K** - Count the number of contiguous subarrays with a product less than k.
9. **Split Into Three Equal Sum Segments** - Check if the array can be split into three parts such that the sums of the parts are equal.
10. **Maximum Consecutive 1s After Flipping 0s** - Find the maximum number of consecutive 1s possible with one flip of a 0.
11. **Last Moment Before Ants Fall Out of Plank** - Find the last moment when an ant falls off a plank.
12. **Find 0 with Farthest 1s in a Binary** - Find the maximum distance of a 0 from the nearest 1 in a binary array.
13. **Intersection of Interval Lists** - Find the intersection of two interval lists.
14. **Rearrange Array Elements by Sign** - Rearrange the elements of an array such that positive and negative numbers alternate, starting with a positive number.
15. **Meeting Scheduler for Two Persons** - Find the time slots when both persons are available.
16. **Longest Mountain Subarray** - Find the longest mountain subarray.
17. **Transform and Sort Array** - Transform the array and then sort it.
18. **Minimum Swaps To Group All Ones** - Find the minimum number of swaps required to group all ones together.
19. **Minimum Moves To Equalize Array** - Find the minimum number of moves needed to make all elements in an array equal.
20. **Minimum Indices To Equal Even-Odd Sums** - Find the minimum indices to make the sum of even indices and odd indices equal.

## Hard Problems

1. **Trapping Rain Water** - Calculate the total amount of rainwater trapped in between the bars.
2. **Maximum Circular Subarray Sum** - Find the maximum contiguous subarray sum in a circular array.
3. **Smallest Missing Positive Number** - Find the smallest missing positive integer in an unsorted array.
4. **Jump Game** - Determine if you can reach the last index starting from the first index.
5. **Closest Subsequence Sum** - Find the subsequence of non-negative numbers that is closest in sum to target.
6. **Smallest Non-Representable Sum in Array** - Find the smallest non-integer value that cannot be represented as the sum of any subsequence in the array.
7. **Smallest Range Having Elements From K Lists** - Find the smallest range that includes at least one number from each of the k sorted lists.
8. **Count Subarrays with K Distinct Elements** - Count all such subarrays in which the number of distinct elements is exactly K.
9. **Next Smallest Palindrome** - Find the next smallest palindrome after the given number.
10. **Maximum Sum Among All Rotations** - Find the maximum sum among all rotations of an array.

# Conclusion
This list of array problems is designed to help candidates practice and improve their problem-solving skills for coding interviews. Each problem comes with a specific challenge and a range of difficulty levels, ensuring that candidates can prepare for various types of questions they might encounter in an interview setting.
